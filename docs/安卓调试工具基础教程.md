
# ADB & Fastboot 安卓调试工具基础教程

## 简要说明

本教程旨在为安卓玩家和开发者提供一个ADB (Android Debug Bridge) 和 Fastboot 的基础命令参考。通过这些命令，你可以更好地管理你的安卓设备、刷机或进行一些高级操作。

### 准备工作

1.  **安装ADB和Fastboot**：你需要从Google官方下载[Platform Tools](https://developer.android.com/studio/releases/platform-tools)并解压。
2.  **开启USB调试**：在你的安卓设备上，进入 "设置" -> "关于手机"，连续点击 "版本号" 7次以开启 "开发者选项"。然后返回上一级菜单，进入 "开发者选项"，打开 "USB调试" 开关。
3.  **连接设备**：使用USB数据线将你的手机连接到电脑。
4.  **运行环境**：打开你电脑的命令行工具（Windows下的CMD或PowerShell，macOS/Linux下的终端），并切换到 `platform-tools` 文件夹所在的目录。所有命令将在此环境下执行。

## 一、ADB 命令 (开机状态)

ADB命令需要在设备完全开机并进入安卓系统后使用。

| 命令 | 功能说明 |
| :--- | :--- |
| `adb devices` | **(最常用)** 检查设备是否成功连接。如果显示设备序列号和 "device" 字样，则表示连接成功。 |
| `adb reboot` | 重启手机，进入系统界面。 |
| `adb reboot-bootloader` | **(常用)** 重启手机并进入 Fastboot (或 Bootloader) 模式。 |
| `adb reboot recovery` | 重启手机并进入 Recovery 模式。 |
| `adb connect <设备IP地址>` | 通过Wi-Fi网络连接到设备。需要先在设备的开发者选项中开启 "无线调试"。 |
| `adb install <文件路径/文件名.apk>` | 从电脑向安卓设备安装一个APK应用。 |
| `adb push <本地文件路径> <设备内路径>` | 将电脑上的文件或文件夹推送到手机指定目录。 |
| `adb pull <设备内文件路径> <本地路径>` | 将手机内的文件或文件夹拉取到电脑指定目录。 |
| `adb logcat` | 查看安卓系统的实时日志，对于排查应用崩溃或系统错误非常有用。按 `Ctrl+C` 停止。 |

## 二、Fastboot 命令 (Bootloader模式)

Fastboot命令需要在特定的Bootloader模式（也称Fastboot模式）下使用。

| 命令 | 功能说明 |
| :--- | :--- |
| `fastboot devices` | **(最常用)** 检查设备在Fastboot模式下是否成功连接。 |
| `fastboot reboot` | **(常用)** 从Fastboot模式重启手机，进入系统界面。 |
| `fastboot reboot-recovery` | 从Fastboot模式重启至Recovery模式。 |
| `fastboot flash <分区名> <镜像文件名>` | **(核心刷机命令)** 向指定分区刷入镜像文件。例如： |
| `fastboot flash boot boot.img` | 刷入`boot`分区 (内核)。 |
| `fastboot flash recovery recovery.img` | 刷入`recovery`分区。 |
| `fastboot oem unlock` | **(谨慎使用)** 解锁设备的Bootloader，这是刷机的第一步。**此操作会清空手机所有数据！** |
| `fastboot oem lock` | 重新锁定Bootloader。 |

## 三、应用管理命令 (ADB Shell)

这些命令通过 `adb shell` 进入设备的Linux命令行环境来管理应用。

### 1. 查看应用包名

首先，你需要获取应用的包名才能进行管理。

| 命令 | 功能说明 |
| :--- | :--- |
| `adb shell pm list packages` | 列出设备上安装的所有应用的包名。 |
| `adb shell pm list packages -s` | 只列出系统应用的包名。 |
| `adb shell pm list packages -3` | 只列出第三方应用的包名。 |
| `adb shell pm list packages [关键词]` | 通过[关键词]搜索包名。 |


### 2. 管理应用

获取包名后，使用以下命令进行操作，只需将 `[应用包名]` 替换为实际的包名即可。

| 命令 | 功能说明 |
| :--- | :--- |
| `adb shell pm uninstall --user 0 [应用包名]` | **(常用)** 卸载应用。`--user 0` 表示为当前用户卸载，常用于卸载预装应用。 |
| `adb shell cmd package install-existing [应用包名]` | 恢复被上述命令卸载的应用。 |
| `adb shell pm disable-user [应用包名]` | **停用**一个应用。效果等同于在系统设置里 "停用"，应用图标会消失。 |
| `adb shell pm enable [应用包名]` | **启用**一个被停用的应用。 |
| `adb shell pm suspend [应用包名]` | **冻结**一个应用。应用数据保留，但无法在后台运行，也不会出现在启动器中。 |
| `adb shell pm unhide [应用包名]` | **解冻**一个被冻结的应用。 |
| `adb shell pm clear [应用包名]` | 清除应用的数据和缓存，效果等同于在系统设置里 "清除数据"。 |

---

### 教程总结

- **ADB** 主要用于开机状态下的调试和文件传输。
- **Fastboot** 主要用于底层刷机操作。
- **ADB Shell** 则提供了更精细化的系统内管理能力，尤其是应用管理。
